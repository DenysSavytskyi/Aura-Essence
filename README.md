# Aura-Essence
Aura Essence je inovatívny online butik so selektívnymi a niche parfumami, ktorý pomáha zákazníkom nájsť ich ideálnu vôňu. Naša platforma ponúka jedinečný algoritmus na výber parfumov na základe osobných preferencií, nálady a ročného obdobia. Spolupracujeme s overenými značkami a nezávislými parfumérmi, aby sme zaručili originalitu a najvyššiu kvalitu produktov. Každý produkt má detailnú vizualizáciu olfaktorickej pyramídy (hlava, srdce, základ), vďaka čomu je proces výberu maximálne zrozumiteľný aj pre začiatočníkov. Aura Essence sa snaží premeniť nákup parfumov z bežného nakupovania na skutočnú cestu do sveta vôní. Pre tých, ktorí váhajú, ponúkame možnosť objednať si sady vzoriek pred kúpou plnohodnotného flakónu. Naším hlavným cieľom je urobiť prémiovú parfumériu dostupnou a proces jej výberu technologickým a pohodlným.
